# 异形数独拼图

- **分类**：Misc / Puzzle　**难度**：中等　**分值**：300
- **形式**：容器题（平台给一个 HTTP 地址，浏览器打开即可作答）
- **Flag 格式**：`SACC{...}`

## 题目描述

给你 **9 块形状各异的碎片**，每块碎片上都印着几个数字。

1. **第一步 —— 拼图**：把 9 块碎片拼成一个 **9×9 的正方形**。
   碎片**不能旋转**（数字必须保持正立），只能平移，所以每个位置都要严丝合缝：9 块 × 9 格 = 81 格，不能重叠也不能留空。
2. **第二步 —— 数独**：拼好之后你会发现，**每行、每列、每块碎片内部**的数字恰好要求 1–9 各出现一次 —— 这是一道「不规则的数独」（碎片就是数独里的「宫」）。

把 **碎片的摆放位置** 和 **完整的 9×9 解** 一起提交，服务器校验通过后会把 flag 给你。

## 玩法提示

- 拼法是**唯一**的：拼错位置时，碎片上的提示数会立刻对不上号（同一行/列出现重复）。
- 数字印在碎片上，碎片搬到哪，提示数就落在哪 —— 所以**先拼图再解数独**。
- 网页端支持：候选标记（小数字）、自动候选、划候选、撤销/重做、计时暂停、即时判错开关。
  顶部有全部快捷键说明（`V/N/E` 换模式、`Shift+数字` 小候选、`Ctrl+Z` 撤销、`P` 暂停）。
- 觉得卡住可以「🧹 重置填写」清空自己填的数字重来（碎片位置保留）；「↩ 收回碎片」则是整题重来。

## 提交方式

在页面右下方点 **「🚩 提交答案」**，页面会把碎片位置 + 完整解发给服务器：
- 正确 → 页面弹出 **通关凭证 · FLAG**，点「复制」拿去平台提交；
- 不正确 → 页面会给出提示（碎片重叠/超出棋盘/某行某列重复……）。
