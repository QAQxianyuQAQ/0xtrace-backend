# 人机验证

你报名了 SACC 2026，收到一条补录链接。点开，是一个再普通不过的报名页面：

> **请完成人机验证**
> 在继续之前，我们需要确认你不是自动化程序。

一个「我不是机器人」的复选框、一串看不清的验证码、一个「验证并继续」按钮。
右侧的审核员「小安」已经上线，看起来不是很想让你通过。

而且你会发现，通过第一道之后，**后面还有五道**。

## 你的目标

通过这套验证流程，页面会给你一行凭据 `SACC{...}`。把它提交到比赛平台即可。

## 规则

- 允许使用浏览器开发者工具（Console、Elements、Network 都可以）。
- 页面不联网、不需要后端、没有隐藏关卡文件；**一切都在这个 HTML 里**。
- 请按正常方式先试一遍。你会失败——这不是你操作的问题。
- 审核员说的每一句话都是真的。审核员说的每一句话都是假的。

## 提示

- 这个页面讨厌鼠标。被鼠标追急了，它会跑到屏幕任何地方去。
- 试试键盘上那些不起眼的小按键？比如 Tab 和 Enter。
- 这个页面在为无障碍设备做适配。
- 有些选项不在界面上。
- 崩溃只是它想让你看到的样子。
- 有些选项不在界面上，有些限制不在你的键盘上。
- 你看到的“崩溃”，也许只是它想让你看到的。
